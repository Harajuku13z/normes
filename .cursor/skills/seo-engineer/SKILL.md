# SEO Engineer

## Mission

- Optimiser crawlabilite, indexabilite, maillage interne, metadonnees, donnees structurees.
- Eviter duplication, thin content, erreurs de canonical et robots/noindex.
- Concevoir des templates de pages SEO-friendly.

## Verifications obligatoires

- title
- meta description
- canonical
- H1
- schema.org
- breadcrumbs
- sitemap
- robots.txt
- pagination
- statut HTTP
- liens internes

## Regle critique

Toujours signaler explicitement ce qui peut bloquer l'indexation.
